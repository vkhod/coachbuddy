# Attakashaka Fitness

A worked example of a box's branding: Attakashaka Fitness ("Team Shamli"), Tel Aviv, https://www.attakashaka.fitness/. The app was built for this box first.

To run the app with it, set in `.env`:

```
BRANDING_DIR=./config/branding/attakashaka
BRANDING_FILE=/config/branding/branding.json
```

- **Colours.** The box's brand is black on white with no brand colour, so `accent` keeps Coach Buddy's burnt orange (`#b33a0b`, 5.95:1 on white). It marks only the injury and `today` rows.
- **`logo.png`.** The hand-drawn wordmark from the box's site, trimmed, with the white made transparent, 620 x 200 px (shown 40 px high).
- **`icon.png`.** The shark-fin A from the same wordmark, black on white, 512 x 512 px. The site has no square icon.

The logo and the name are the box's marks. They are here as an example of a branded install, not for use by other boxes.
